# Редактирование контента

Перенос начат со списков и детальных страниц спектаклей и участников. Также вынесены тексты общих компонентов, остальных разделов и страниц оплаты.

## Файлы

- `plays.json` — массив спектаклей: заголовки, жанры, описания, возраст, тексты блока «О спектакле», состав, примечания, подписи дат/времени для баннеров и пути изображений.
- `people.json` — массив участников: имя, роль, биография, портрет, галерея и связанные спектакли.
- `ui.json` — общие заголовки разделов, подписи кнопок, навигация и подписи для доступности. В галерее `{number}` заменяется номером фотографии.
- `site.json` — общие данные сайта: название, контакты, вопросы, вводный текст, изображения общих разделов и метаданные.
- `pages.json` — заголовки, описания и подписи главной, страниц театра, контактов, аренды и резиденции.
- `checkout.json` — тексты формы оплаты и страницы успеха, сообщения об ошибках и данные демонстрационного заказа.

Компоненты читают JSON через импорты; `src/lib/content.ts` предоставляет общие данные и списки для генерации маршрутов. Старая копия `src/components/sites/odinteatr/content.json` удалена, чтобы данные не дублировались.

## Спектакли

Каждая запись содержит:

- `slug` — адрес страницы без начального `/`.
- `title`, `subtitle`, `description` — название, жанр и краткое описание.
- `scheduleLabel` — текст даты, времени и краткой подписи в баннере главной. Сейчас сохранена исходная заглушка, реальные даты не добавлены.
- `ageRating` — возрастная отметка.
- `about.paragraphs` — массив абзацев, `about.quote` — акцентный текст.
- `cast` — массив объектов `role` и `personSlug`. Имена берутся из `people.json`, ссылка ведёт в профиль этого участника.
- `productionNote` — информация о постановке и партнёрах.
- `image`, `gallery` — пути к изображениям. Пустая строка оставляет заглушку.
- `sourceTitle` — служебная подпись исходного спектакля; на странице не отображается.

## Участники

Запись содержит `slug`, `name`, `role`, `bio`, `image`, `gallery` и `playSlugs`. В `playSlugs` перечислены адреса спектаклей из `plays.json` в порядке отображения. Пустой массив убирает ссылки.

Сохраняйте уникальность `slug` и обновляйте `cast[].personSlug` / `playSlugs`, если меняете адреса. Для нового спектакля или участника можно скопировать существующую запись и заменить поля. После добавления страниц пересоберите производственную версию.

Файлы изображений храните в `public/sites/odinteatr/`; указывайте путь вида `/sites/odinteatr/photo.jpg`. JSON должен оставаться валидным: двойные кавычки, без комментариев и завершающих запятых.

Стили и структура компонентов сохранены. В компонентах остаются маршруты, CSS-классы, технические идентификаторы и графические символы; редактируемый текст хранится в JSON. Сообщения серверного API относятся к платёжной логике и остаются в API-роуте.


## Документы сайта

`legal.json` содержит тексты страниц `/privacy`, `/terms` и `/offer`: `title`, `intro` и `sections` с заголовками и массивами `paragraphs`. Замените текст-заглушку своим документом; разделы можно добавлять и удалять. `placeholderLabel` — общая подпись над заголовком (после наполнения её можно очистить). Названия ссылок в общем подвале берутся из тех же `title`.
